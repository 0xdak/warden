Install

  1. Open the disk image

    Double-click {{name}}.dmg and drag {{name}} into Applications.

  2. Open {{name}} from Applications

    The app is signed with an Apple Developer ID and notarized by Apple, so macOS only shows its usual “downloaded from the internet” confirmation on first launch. A shield icon appears in the menu bar and the setup window opens.

  3. Tick your agents and press Install

    Setup lists the agents it found. Tick the ones to protect, pick how strict to be (Balanced is recommended) and press Install & continue. Nothing is protected until you do this. It adds one hook to each agent’s settings and saves a backup first.

    Closed the window or skipped it? Click the shield in the menu bar, open Agents and press Install next to each agent. Until then the shield shows a warning.

  4. Restart running agents

    New sessions pick up the hook. Codex: run /hooks once and trust the new hook. Cline: switch the hook on in Cline’s Hooks tab. When the baseline looks right, press Start enforcing on Home.

Build from source

{{name}} is open source under the MIT License. With the Command Line Tools installed (xcode-select --install, no Xcode needed):

git clone {{repoUrl}}.git
cd "$(basename {{repoUrl}})/app"
scripts/selftest       # runs every rule check against a throwaway home folder
scripts/build_app.sh   # → dist/{{name}}.app

The repository README has the details. A build you make yourself is signed ad hoc, so macOS asks you to confirm its first launch in System Settings → Privacy & Security.

What it changes on your Mac

  • One hook entry in each protected agent’s settings file, such as ~/.claude/settings.json or ~/.cursor/hooks.json. Your own hooks and settings stay. A backup of each file is saved first.
  • A folder at ~/Library/Application Support/{{name}} with settings, remembered decisions, the evidence log and the hook helper.
  • Nothing else. No admin rights, no Full Disk Access, no background services besides the menu-bar app.

Uninstall

In {{name}}, open Agents and press Remove for each agent; Restore backup puts back the exact file saved before install. Quit {{name}} from the menu bar and delete it from Applications. Optionally delete its folder in Application Support.

Deleted the app first? Remove the entries that point to Application Support/{{name}}/bin from the agent settings files, and agents will stop calling it.
