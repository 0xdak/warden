The app

What it processes, and where

When an AI coding agent you’ve connected is about to act, the agent passes details of that action to {{name}}’s hook helper. Depending on the agent and the action, these can include:

  • the tool name (for example a shell command, file read or MCP tool);
  • the command text, file path or URL;
  • the project folder, the agent’s name and a session identifier;
  • for prompt checks, the prompt text.

These are evaluated against your rules on your Mac only. To build the activity log, {{name}} stores a summary of each action and its decision in local log files inside its folder in your user Library. Before saving, values that look like secrets (keys, tokens, passwords) are masked and file contents are not stored. You choose how long the log is kept, and you can delete it at any time from the app.

When it installs hooks, {{name}} saves backup copies of the agent configuration files it changes, also locally, so it can restore them.

What it doesn’t do

  • No user accounts. It never asks for your email.
  • No analytics, telemetry, advertising or third-party SDKs.
  • No uploads of code, prompts, commands, paths, logs, rules or secrets.
  • No automatic crash reports. If you want to send one, you email it yourself and see exactly what you share.
