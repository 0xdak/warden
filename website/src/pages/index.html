How it works

  1. It uses the agent’s own hooks.

    Setup adds one entry to each agent’s settings file and saves a backup of that file first. No proxy, no kernel extension, nothing changes in how you start the agent.

  2. It decides on your Mac, before the action runs.

    A small helper checks each call against built-in rules: block the clear threats, ask about judgment calls, let everything else through. Hard blocks work even when the app is closed.

  3. It starts by watching.

    You can begin in observe mode. {{name}} logs what it would have stopped, you adjust the rules, and when the log looks right you press Start enforcing.

Questions

Does it slow the agent down?

Not noticeably. Each check is a small native program that answers from local rules, with no network round trip. You only wait when {{name}} asks you something.

What happens if the app isn’t running?

Hard blocks still apply, because the helper decides on its own. For questions, Claude Code and Cursor fall back to their own permission prompt. For the other agents you choose what happens in Settings; the default is to block and tell the agent to ask you to open {{name}}.

What if I don’t answer a popup?

After 60 seconds the action is blocked. Both the wait and the fallback can be changed in Settings. On high-risk questions, Return and Esc both choose Block.

Can an agent get around it?

Sometimes. Hooks see what the agent says it will do, so a script written now and run later, or heavy obfuscation, can slip past pattern rules. {{name}} also blocks edits to its own hooks and warns when they disappear. The full list is on What it doesn’t catch. Found a way around a rule? Report it privately.

Is it really free? Can I read the code?

Yes. {{name}} is open source under the MIT License, with no paid tier. The rules, the hook helper and the app are all on GitHub, and you can build it yourself with the Command Line Tools. Release builds are signed with an Apple Developer ID and notarized by Apple.

How do I remove it?

On the Agents screen, press Remove for each agent. Only {{name}}’s entries are taken out, and Restore backup puts back the exact file saved before install. Then quit the app and delete it.
