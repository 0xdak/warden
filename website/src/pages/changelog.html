0.1.1

2026-11-17

Harder to bypass, harder to miss

  • Secret rules follow symlinks, expand globs (cat .e*), resolve same-line variables and read python -c / node -e one-liners.
  • Deletes are judged on the real target path: home, system folders, parents of the project and .git are blocked; anything else outside the project asks. The approval panel shows the resolved path.
  • New checks: decoded scripts piped to a shell, download-then-run, cloud metadata endpoints, infra destroy commands, Docker host mounts and edits to shell startup files.
  • Oversized commands ask instead of slowing the hook down; a normal check takes a few milliseconds.
  • If no agent is protected, Home and the menu bar say so with a one-click install, and setup can't quietly finish without protection. Observe mode notifies you about what it would have stopped.
  • Fewer false alarms: listing ~/.ssh or adding .env to .gitignore is no longer flagged.

0.1.0

{{releaseDate}} {{channel}}

First public beta

  • Hook installer for Claude Code, Codex CLI, Cursor, Gemini CLI, Windsurf and Cline, with a backup before every change and a clean uninstall.
  • Built-in rules for secret files, destructive commands, git history rewrites, remote scripts piped to a shell, exfiltration and environment dumps.
  • Allow, ask, block and observe decisions, with Strict, Balanced and Permissive presets.
  • Approval popup with Allow once, Allow for project and Block. Return blocks on high-risk actions; no answer falls back to the rule’s default.
  • Activity log of every action, searchable by agent, project, decision and time, with secret-looking values masked.
  • Menu-bar status with today’s counts, recent blocks, and pausing for 15 minutes or an hour.
  • Warnings when an agent runs in a skip-permissions mode or when hooks are removed or disabled.
