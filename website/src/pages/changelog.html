0.1.0

{{releaseDate}} {{channel}}

First public beta

  • Hook installer for Claude Code, Codex CLI, Cursor, Gemini CLI, Windsurf and Cline, with a backup before every change and a clean uninstall.
  • Built-in rules for secret files, destructive commands, git history rewrites, remote scripts piped to a shell, exfiltration and environment dumps.
  • Allow, ask, block and observe decisions, with Strict, Balanced and Permissive presets.
  • Approval popup with Allow once, Allow for project and Block. Return blocks on high-risk actions; no answer falls back to the rule’s default.
  • Activity log of every action, searchable by agent, project, decision and time, with secret-looking values masked.
  • Menu-bar status with today’s counts, recent blocks, and pausing for 15 minutes or an hour.
  • Warnings when an agent runs in a skip-permissions mode or when hooks are removed or disabled.

This is a beta: expect rough edges, and tell us about them at {{contactEmail}}.
